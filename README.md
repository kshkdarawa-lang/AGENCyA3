# AGENC A3 — FIXED v6

هذه النسخة تصلح مشكلة:
`Unexpected token '<', "<html>..." is not valid JSON`

## لماذا ظهرت المشكلة؟
GitHub Pages يستضيف ملفات الواجهة فقط. عندما كانت الواجهة تطلب `/api/login` من نفس نطاق GitHub Pages، كان GitHub يعيد صفحة HTML، بينما JavaScript كان يتوقع JSON.

## ما تم إصلاحه
- إضافة حقل **رابط السيرفر** عند فتح الموقع من GitHub Pages.
- كل طلبات API تستخدم رابط السيرفر المحفوظ.
- رسالة خطأ واضحة إذا رجع السيرفر HTML بدل JSON.
- دعم CORS في السيرفر.
- WebSocket أصبح يستخدم نفس السيرفر الخلفي.
- إضافة موسيقى تجريبية تعمل من `/music/agenc-a3-test-music.wav`.
- إمكانية اختيار ملف صوت من الهاتف للتجربة.
- الحفاظ على التسجيل، الدخول، الأصدقاء، الرسائل، الهدايا، اللعبة والغرف.

## التشغيل الحقيقي
### 1) شغّل السيرفر والقاعدة
على VPS أو جهاز عليه Docker:
```bash
docker compose up --build -d
```

### 2) افتح السيرفر
إذا كان الدومين:
`https://api.example.com`
ضعه داخل مربع **رابط السيرفر** في الموقع.

### 3) GitHub Pages
ارفع مجلد `public` إلى GitHub Pages، أو ارفع المشروع بالطريقة التي تستخدمها حاليًا.

> GitHub Pages وحده لن يحفظ الحسابات؛ يجب أن يكون Node + PostgreSQL شغالين على VPS/استضافة خلفية.

## قبل النشر العام
- غيّر كلمات مرور PostgreSQL وJWT_SECRET.
- استخدم HTTPS وWSS.
- أضف TURN للصوت.
- للغرف الكبيرة استخدم SFU مثل LiveKit أو mediasoup.

## موسيقى الغرفة — رفع من الهاتف
- بعد تسجيل الدخول ودخول الغرفة، يظهر قسم **موسيقى الغرفة**.
- اختر ملفًا صوتيًا من الهاتف (MP3/WAV/M4A/AAC/OGG/OPUS/FLAC) بحد أقصى 25MB.
- اضغط **تحميل للهاتف/السيرفر** لرفع الملف إلى الـBackend.
- اضغط **تشغيل في الغرفة** لإرسال الأغنية لجميع الموجودين في الغرفة.
- زر الإيقاف يرسل حالة الإيقاف لجميع أعضاء الغرفة.
- رفع الأغاني يحتاج تشغيل الـBackend، وليس GitHub Pages فقط.
