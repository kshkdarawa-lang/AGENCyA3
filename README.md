# AGENC A3 FINAL v5

نسخة موحدة جاهزة للنشر والتطوير.

## المنجز
- تسجيل وإنشاء حسابات مع كلمات مرور مجزأة بـ bcrypt.
- جلسات JWT.
- PostgreSQL للحسابات، العملات، سجل المعاملات، الأصدقاء، الرسائل، الغرف والهدايا.
- غرف صوت WebRTC + WebSocket signaling.
- 8 مقاعد + مضيف + رفع اليد + كتم + طرد.
- هدايا وخصم عملات من الخادم داخل transaction.
- لعبة نرد بمكافآت محدودة من الخادم.
- واجهة عربية RTL متجاوبة.
- Dockerfile و docker-compose.

## التشغيل السريع
انسخ المشروع إلى جهاز/سيرفر عليه Docker ثم:
docker compose up --build

بعدها افتح:
http://localhost:3000

## مهم قبل النشر العام
1. غيّر POSTGRES_PASSWORD و JWT_SECRET في docker-compose.
2. استخدم HTTPS/WSS.
3. أضف TURN server.
4. للغرف الكبيرة استبدل Mesh بـ SFU مثل LiveKit أو mediasoup.
5. اربط دومين وreverse proxy مثل Nginx/Caddy.
6. راجع نظام المدفوعات والعملة قانونياً قبل تحويل العملات إلى أموال حقيقية.


## V6 - تجربة الموسيقى والحساب
هذه النسخة تضيف واجهة موسيقى تجريبية واضحة داخل التطبيق، مع بقاء التسجيل/الدخول والحسابات وقاعدة البيانات الموجودة في V5.

### تجربة الحساب
1. شغّل المشروع بـ Docker Compose.
2. افتح التطبيق.
3. من شاشة الدخول اختر إنشاء حساب.
4. أدخل اسم المستخدم وكلمة المرور.
5. بعد التسجيل سجّل الدخول بالحساب.
6. جرّب الغرفة الصوتية والمقاعد والرسائل والهدايا.
7. من قسم 🎵 الموسيقى اختر مقطعًا ثم اضغط تشغيل.

> ملاحظة: المقاطع في مشغل الموسيقى روابط تجريبية عامة للتجربة فقط. للاستخدام التجاري أو العام، استبدلها بملفات/روابط موسيقى لديك حق استخدامها.
